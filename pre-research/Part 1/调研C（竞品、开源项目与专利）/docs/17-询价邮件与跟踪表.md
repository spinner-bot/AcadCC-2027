## 询价时必须记录的字段

| 字段 | 为什么要 |
|---|---|
| 主体数 | 多数厂商按法人主体/账套计价 |
| 用户数 | 审核、财务、管理员是否分开计价 |
| 月单据量 | 发票量常影响档位和 OCR/接口费 |
| 模块 | 三单、查验、OCR、归档、付款是否分开卖 |
| 数电票 XML/OFD | 决定是否能跳过扫描件 OCR |
| 实施/接口费 | 首年总成本的主要隐藏项 |
| 年维护/订阅费 | 不能只比较首年 |
| 试用/POC | 验证真实流程，而不是只看 PPT |
| 参考客户 | 要求同规模、同行业、同模块 |

## 重要边界

- 不要用“我们已经决定采购”换取报价；这是不实陈述，也可能导致后续无法履约。
- 不要索取客户合同价、保密报价或未公开客户名单。
- 厂商给的“起步价”通常不含实施、接口、归档和税费，必须追问总拥有成本。
- 如果对方只愿意电话沟通，记录对方姓名、日期、版本和报价口径，不要只记一个总价。
- 本文件是调研模板，不构成采购建议。
