# 数据来源与取证路径

> 2026-10-17　目的：回答"竞品数据能不能拿到、能拿到什么级别"

## 一句话

**能力层面的数据大约 70–80% 公开可查；价格、内部规则、真实准确率拿不到。**
矩阵只需要"公开可查"就能填完，但必须把证据等级标出来，否则会被当成厂商宣传。

## 四级数据（矩阵里应按这个分级标注）

| 级别 | 内容 | 能否引用 |
|---|---|---|
| A · 可直接引用 | 官方文档、帮助中心、API 文档、版本发布说明、公开专利、招标文件、上市公司年报 | 可，标"官方文档" |
| B · 需甄别 | 官网营销页、白皮书、演示视频、第三方评测、用户社区 | 可，标"厂商自述"或"第三方" |
| C · 需申请 | 试用账号、沙箱、销售演示、实施商访谈 | 可，标"实测/访谈" |
| D · 拿不到 | 内部规则阈值、模型细节、真实准确率、合同价、源码 | 只能写"未确认" |

**注意**：B 级不能证明"支持"，只能证明"厂商声称支持"。矩阵里的 `支持` 至少要 A 级或 C 级。

## 去哪儿拿（按厂商）

### 国际 ERP
- SAP：`help.sap.com`（产品文档）、`api.sap.com`（接口）、SAP Community、SAP Note
- Oracle：`docs.oracle.com`（Fusion Cloud ERP 文档）、Oracle Cloud Marketplace
- Microsoft：`learn.microsoft.com`（Dynamics 365 Finance 文档）

### 国际 AP 专业厂商
- Coupa / Basware / Ivalua / JAGGAER：官网产品页 + 客户帮助中心（部分需登录）
- Medius / Esker / Tungsten / Stampli / Yooz / Tipalti：官网产品页 + 帮助中心 + YouTube 官方演示
- Vic.ai / AppZen / HighRadius / Auditoria：官网 + 白皮书 + 公开演示视频

> 这一层很多文档要客户账号。拿不到就退到 B 级：官方演示视频 + 产品页截图。

### 国内
- 用友：`yonyou.com` 产品页、用友云市场、开发者文档
- 金蝶：`kingdee.com`、金蝶云社区 `vip.kingdee.com`
- 汇联易 / 每刻 / 合思 / 元年：官网产品页 + 帮助中心 + 公众号案例
- 云砺（票易通）/ 百望云 / 航天信息：官网 + 开放平台文档（若有）
- 实在智能 / 来也 / 艺赛旗：官网 + 产品演示视频

### 通用补充源
- 用户评价：G2、Capterra（看**差评**，比好评有用）
- 专利：`patents.google.com`、`worldwide.espacenet.com`、`cnipa.gov.cn`
- 价格与真实功能清单：**中国政府采购网 `ccgp.gov.cn` 的招标/中标公告**（国内最实用的一招）
- 上市公司：巨潮资讯 `cninfo.com.cn` 年报里的"主营业务/产品"章节
- 招聘 JD：看对方在招什么岗位，能反推产品阶段与技术栈

## 拿不到的四样（别浪费时间）

1. **内部规则与阈值**：容差怎么算、风险分怎么加权，不会公开
2. **真实准确率**：没有第三方评测就没有可信数字
3. **合同价**：官网一律"联系销售"，只能靠招标公告或访谈
4. **私有化部署的代码**：不开放

对应写法：`未确认` / `需实测` / `价格未公开`，不要猜。

## 48 小时 desk research 路线

| 时段 | 做什么 | 产出 |
|---|---|---|
| 第 1 天上午 | 每家找 1 份官方产品文档，定位"匹配/容差/复核"章节 | 每家有 1 个可引用链接 |
| 第 1 天下午 | 看 3–5 个官方演示视频，记录"差异产生后界面发生什么" | 交互流程笔记 |
| 第 2 天上午 | 搜 G2/Capterra 差评 + 知乎/脉脉讨论 | 已知痛点清单 |
| 第 2 天下午 | 政府采购网搜"三单匹配/发票管理/财务共享"中标公告 | 价格区间 + 功能清单 |

## 试用申请话术

不要写"学生调研"，会被转给市场部。写：

> 我们在做应付账款自动化的选型评估，想确认三个点：三单匹配的粒度、差异处理的流程、能否对接电子凭证标准。希望申请一个测试账号，两周内给反馈。

对方给试用最好；不给就要求 20 分钟产品演示，并提前把五个问题发过去。

## 销售演示怎么问（别听介绍，直接问）

1. 请用一笔**数量不一致**的单据演示，不要用金额一致的样例
2. 差异出现后，系统给出的下一步是什么？点给我看
3. 这个结论能不能点到原始单据的具体字段？
4. 复核记录在哪里看？能不能导出底稿？
5. 数电票 XML 能不能直接导入，还是只能上传 PDF/图片？

**要对方现场操作，不要看录好的 demo。**

## 引用纪律

- A 级：`[官方文档] 产品/版本/页面标题/链接/检索日期`
- B 级：`[厂商自述] …`，不得写进"支持"结论
- C 级：`[实测] 环境/日期/操作路径/截图`
- D 级：`未确认`

矩阵里一个 `支持`，背后至少要有一张证据卡；卡上的等级决定这句话能不能对外说。
