# 价格与客户证据

> 日期：2026-10-18  
> 范围：`01-竞品能力矩阵.csv` 的 13 个对象  
> 口径：价格只记录官网公开价、公开价目表或明确的“需询价/免费试用”；客户证据优先记录具名案例、客户数量及其来源  
> 重要边界：厂商官网的客户 logo、案例和“服务 X 家企业”均为**厂商自述**，不是独立审计数据；本轮没有把 logo 当作“已采购/已上线”的充分证明

## 一页结论

1. **公开标价几乎不存在。** 13 家里只有 Medius 公开了套餐层级但没有数字价格；国内几家普遍是“免费试用/预约演示/获取报价”，企业级项目仍需询价。
2. **客户证据比价格证据多，但主要是厂商自述。** 金蝶、汇联易、每刻、合思、用友和 Medius 都能取到具名案例或客户数量；其余海外厂商本轮被反爬/安全验证拦截。
3. **不能做价格排名。** 没有统一的用户数、单据量、 entity 数和模块范围，任何“谁贵谁便宜”的结论都会失真。
4. **可以做采购前的询价模板。** 用同一场景向各家要报价：3 个法人主体、每月 1,000 张发票、10 个审核用户、订单/收货/发票三单、数电票 XML/OFD、电子归档。

## 这些证据能支持什么、不能支持什么

| 可以写 | 不要写 |
|---|---|
| “Medius 公开套餐但要求询价” | “Medius 价格是 X 元/年” |
| “金蝶、汇联易、每刻、合思官网有具名案例” | “这些客户都用了三单匹配模块” |
| “汇联易自述 3000+ 企业客户” | “汇联易有 3000 个付费且上线的 AP 客户” |
| “国内厂商普遍采用免费试用/预约演示” | “国内厂商没有公开价格，所以都很贵” |
| “本轮未取到 SAP/Oracle 等客户页” | “SAP/Oracle 没有客户案例” |

## 下一步

1. 用同一询价模板向 3 家国内厂商要报价，记录：主体数、用户数、单据量、模块、实施费、归档费、优惠。
2. 为每个“支持（C3–C6）”找一条独立证据：客户公告、招投标、年报或新闻稿，把厂商自述升级为 L1/L2。
3. 海外厂商优先补 Medius、Basware、Coupa、Tipalti 的公开客户案例；SAP/Oracle 至少补一条官方具名案例。
4. 把价格列更新为“公开价/询价/试用”三态，不把“未公开”写成“没有价格”。
