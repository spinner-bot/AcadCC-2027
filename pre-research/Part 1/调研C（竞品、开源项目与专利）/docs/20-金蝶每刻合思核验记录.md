1. **每刻是直接竞品，不是相邻产品。** 其 AI 应付页明确写“采购订单、入库单、发票自动三单匹配”，并写到“发票明细和单据明细的逐行匹配”“匹配后自动生成应付单”。三单匹配不能再作为我们的独立创新点。

4. **三家都没有公开证据证明“字段级证据依赖图 + 矛盾归因 + 可审计人机协同”。** 这是目前仍然可争的差异点，但只是“公开材料未见”，不是“竞品一定没有”。

## 对 C 方向结论的影响

1. **三单匹配正式确认是红海。** Oracle、Medius、每刻都有直接产品证据；合思已经用“四单匹配”作卖点。原选题不能把“三单匹配”当创新点。
2. **“AI + 发票 + 应付 + 档案”也是一体化竞争。** 每刻把三单、查验、查重、应付、档案串成一条线；合思把付款、采购、档案、AI 审核串成一条线。单点功能很难形成差异。
3. **仍然可争的空间没有变：跨单据字段级证据依赖图、矛盾归因、人在环可审计决策。** 但三家公开页都没有把这三点讲清楚，所以只能写“公开材料未见”，不能写“竞品不做”。
4. **金蝶必须继续核。** 它是国内 ERP 主力，公开页没写不代表没有；下一步要拿产品手册、实施配置清单或演示，重点问三单匹配、容差、异常工作流、数电票直读。
